# SoraVideo (Kage · 影)

SoraVideo is CuteClaudia's video editor, part of the SoraSpace suite (https://www.soraspace.studio).
This repository holds its published versions: download them from **Releases**, and report
problems or send feedback under **Issues**. Installed copies check here for updates.

SoraVideo is built on FilmCraft (MIT OR Apache-2.0); see the NOTICE file in each download.
